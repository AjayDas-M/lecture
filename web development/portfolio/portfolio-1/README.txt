PERSONAL PORTFOLIO STARTER

1. Extract the folder.
2. Open index.html in a modern browser.
3. Replace placeholder text such as "Your Name", degree, institution, and project descriptions.
4. Put your profile image at assets/profile.jpg.
5. Put your PDF resume at assets/resume.pdf.
6. Update the GitHub, LinkedIn, project, and email links in index.html.

Files:
- index.html: semantic page structure
- css/style.css: monochrome responsive styling and light theme
- js/script.js: theme toggle and mobile navigation

This is a static frontend starter. The contact email link opens the visitor's default email app; it is not a backend contact form.
