# Ajay Das M. — Portfolio Website

A responsive, single-page portfolio starter built with HTML5, CSS3, and vanilla JavaScript.

## Run it
1. Extract the folder.
2. Open `index.html` in a browser. For a smoother development experience, use VS Code with the Live Server extension.
3. Replace the placeholder assets and details below.

## Replace these placeholders

- **Profile photo:** `assets/images/profile.jpg`
- **Project screenshots:** `assets/images/projects/project-1.jpg` and `project-2.jpg`
- **Achievement photos/certificates:** `assets/images/achievements/achievement-1.jpg` and `achievement-2.jpg`
- **Resume:** add your PDF as `assets/resume.pdf` if you later add a resume download link.
- **Education:** update institution names and any coursework in `index.html`.
- **Projects:** update project names, descriptions, technology tags, and real URLs in `index.html`.
- **Email:** replace `your.email@example.com` in `index.html` and `contactRecipient` in `js/script.js`.
- **GitHub / LinkedIn:** replace the placeholder URLs and labels in `index.html`.

## Contact form note
This starter uses `mailto:` to prepare an email in the visitor's default email app. It does not send messages directly from the website. For a true on-page submission, connect a form service or backend.

## Customize
- Colors, layout, typography, and responsive breakpoints: `css/style.css`
- Dark mode, mobile navigation, image lightbox, contact form behavior: `js/script.js`
- Page text, sections, image paths, and links: `index.html`
